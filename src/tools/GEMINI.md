# tools/
> L2 | Parent: ../GEMINI.md

Pure client-side HTML5 Canvas, Blob, binary EXIF/PDF, dynamic HEIC/WebP WASM, ONNX Runtime Web (WASM) MODNet FP16 portrait matting, and JSZip image processing engines. Zero external network calls; every engine separates pure layout geometry from injectable Canvas 2D rendering for deterministic testing.

Member list
- `types.ts`: Shared input, option, layout, canvas abstraction, vertical seam telemetry, PDF mode, target-KB compression, and result interfaces across all processing engines (re-exports `idPhotoTypes.ts`).
- `idPhotoTypes.ts`: Shared ID photo preset, portrait matting, anti-halo rendering, and 300 DPI print sheet interfaces.
- `idPhotoSpecs.ts`: Canonical global 300 DPI ID photo preset catalog (`ID_PHOTO_SPECS`), standard backdrop swatches (`ID_PHOTO_BACKGROUNDS`), locale-prioritized ordering (`getOrderedIdPhotoSpecs`), lookup (`findIdPhotoSpec`), and millimeter-to-pixel conversion (`mmToPixels`).
- `portraitMattingMath.ts`: Pure CPU pixel-math primitives for O(N) sliding-window Guided Image Filter (`guidedFilterAlpha`), CIELAB + border-connected flood-fill studio backdrop swap (`computePureBackdropAlpha`), robust outer backdrop estimator (`estimateOuterBackgroundRgb`), foreground color decontamination (`decontaminatePixelRgb`), and portrait auto-framing (`detectPortraitFramingFromAlpha`).
- `portraitMatting.ts`: 100% browser-local MODNet FP16 (`onnxruntime-web/wasm` + local hashed `.wasm`/`.mjs` assets + Cache API) portrait matting runtime (`extractPortraitMatte`), deterministic test overrides (`setPortraitMattingOverride`, `resetPortraitMattingCache`), and re-exports of `portraitMattingMath.ts`.
- `idPhotoPrintSheet.ts`: 300 DPI 4R 6-inch & A4 print sheet layout solver (`computeIdPhotoSheetLayout`) and exterior-cut-mark PNG / PDF 1.4 renderer (`composeIdPhotoPrintSheet`).
- `idPhotoEngine.ts`: Zero-halo ID photo compositor (`renderIdPhoto`), aspect-locked pan/zoom crop solver (`computeIdPhotoCropSourceRect`), exact-dimension exam target-KB JPEG binary search, White/Blue/Red multi-color trio ZIP builder (`composeIdPhotoTrioZip`), and re-exports of `idPhotoPrintSheet.ts` and `detectPortraitFramingFromAlpha`.
- `webpEncoder.ts`: Lazy client-side libwebp WASM encoder (`encodeWebpWithWasm`, `resetWebpWasmEncoderCache`, `setWebpWasmEncoderOverride`) dynamically importing `@jsquash/webp/encode` plus local `.wasm?url` binaries only when native browser Canvas WebP encoding is unavailable (0 KB main-bundle impact, zero `eval`/`new Function`).
- `canvasHelpers.ts`: Offline image loader with `URL.revokeObjectURL` lifecycle, 8192px/64MP dimension clamp, rounded-rect clipping, solid/gradient fill, Canvas format capability detection (`canEncodeCanvasFormat`, `resetCanvasFormatProbeCache`, `resolveEncodedImageFormat`), canvas-to-Blob encoding with WebKit/Safari lazy WASM WebP fallback before opaque JPEG fallback, byte formatter, and `packBlobsToZip` via `jszip`.
- `heicDecoder.ts`: Native-first local HEIC/HEIF detector (`isHeicFile`) and decoder (`decodeHeicToBlob`) falling back to lazy dynamic `import('heic-to/csp')` (zero `eval`/`new Function`, 0 KB main-bundle impact) with injectable hooks for Node tests.
- `exifReader.ts`: Zero-dependency pure `DataView` binary EXIF & GPS inspector (`parseExifFromBuffer`, `readExifSummary`) supporting JPEG `APP1`, PNG `eXIf`, WebP `EXIF`, and ISOBMFF/HEIC `Exif` payloads without ever throwing.
- `pdfHelper.ts`: Zero-dependency single- and multi-page PDF 1.4 binary builder (`buildSinglePagePdfBytes`, `createSinglePagePdfFromJpeg`, `buildMultiPagePdfBytes`, `createMultiPagePdfFromJpegs`) supporting ISO A4 portrait/landscape, fit-to-image sizing, 36pt margins, white backgrounds, and 20-byte `xref` tables via `/DCTDecode`.
- `stitchOverlap.ts`: Pure client-side 2D pixel overlap, fixed top/bottom bar detector, main-thread yielding async stitch analyzer (`yieldToMain`, `detectVerticalStitchOverlapsAsync` with 50ms INP budget via `scheduler.yield()` / `setTimeout`), and manual seam-override resolver (`computeRowProfile`, `detectPairOverlap`, `extractNormalizedRaster`, `detectVerticalStitchOverlaps`, `applySeamOverlapOverrides`) for vertical long-screenshot deduplication with safe 16px clamping and fallback when `getImageData` is unavailable.
- `mergeEngine.ts`: Horizontal side-by-side, vertical long-image stitch (with automatic main-thread-yielding `removeOverlap` deduplication via `detectVerticalStitchOverlapsAsync`, `seamOverlapOverrides`, and `seams`/`overlapRemovedPx` reporting), and 2..6 column grid collage layout solver (`computeMergeLayout`) and Canvas renderer (`mergeImages`) with cross-axis alignment, per-item 90° rotation, per-image border strokes, and PNG/JPEG/WebP/single- or multi-page PDF export.
- `splitEngine.ts`: Seamless social carousel panorama (`4:5`, `3:4`, `1:1`, `auto`) and `1..6 x 1..6` grid matrix splitter (`computeCarouselSlices`, `computeGridSlices`, `splitImage`) with ZIP export.
- `compressEngine.ts`: Local batch WebP/JPEG/PNG compressor and downscaler (`computeCompressedDimensions`, `compressImage`, `compressImages`) preserving WebP alpha transparency, with 7-iteration `targetBytes` quality binary search, optional iterative width auto-downscaling (320px floor), exact byte-savings metrics, and ZIP archive.
- `transformEngine.ts`: Batch resize, normalized/preset crop, and non-cropping border/pad engine (`computeResizeGeometry`, `computeCropGeometry`, `computePadGeometry`, `transformImage`, `transformImages`) with shadow and gradient support.
- `idCardEngine.ts`: Privacy-first offline A4 (300/150 DPI) ID-1 physical card (`85.6mm x 54mm`) composer (`computeIdCardSheetLayout`, `composeIdCardSheet`) with photocopy B&W filter and tiled or across-card anti-fraud watermark.
- `annotateEngine.ts`: Pure client-side vector image annotation engine with immutable undo/redo history (`createAnnotationHistory`, `pushAnnotationHistory`, `undoAnnotationHistory`, `redoAnnotationHistory`, `canUndoAnnotation`, `canRedoAnnotation`), iterative RDP brush thinning (`simplifyBrushPoints`), C1 quadratic SVG path builder (`buildSmoothSvgPath`), normalized bounds/move/8-handle resize geometry (`getAnnotationBounds`, `computeResizedBounds`, `moveAnnotationLayer`, `resizeAnnotationLayer`), z-order hit testing (`hitTestAnnotationLayers`), contrast-halo Canvas 2D renderer (`renderAnnotationsToCanvas`), and clamped full-res compositor (`renderAnnotatedImageToBlob`).
- `index.ts`: Public barrel re-exporting all engines (including ID photo & portrait matting and vector annotation), HEIC decoder, lazy WASM WebP encoder, EXIF inspector, overlap & seam resolver, PDF builders, helpers, constants, and types.
- `testHelpers.ts`: Deterministic recording `CanvasLike` / `CanvasContextLike` test doubles (with optional `pixelBacked` RGBA buffer) and mock image factory for Node Vitest suites.
- `idPhotoEngine.test.ts`: Unit tests for `idPhotoSpecs`, `guidedFilterAlpha`, `computePureBackdropAlpha` interior-white protection, `decontaminatePixelRgb` anti-halo white-to-red compositing, `detectPortraitFramingFromAlpha`, `computeIdPhotoCropSourceRect`, `renderIdPhoto` exact-dimension target-KB search, `composeIdPhotoTrioZip`, and `composeIdPhotoPrintSheet` (4R 6-inch & A4 PNG + PDF 1.4).
- `annotateEngine.test.ts`: Unit tests for annotation undo/redo history, RDP brush simplification, quadratic SVG path output, 8-handle resize clamping, move/resize geometry, z-order hit testing, Canvas 2D brush/rect/arrow/text halo rendering, and full-res Blob/dataUrl composition.
- `webpEncoder.test.ts`: Unit tests for WASM WebP quality clamping/mapping, RGBA validation, injectable and override hooks, ArrayBuffer/Uint8Array Blob conversion, and cache resets.
- `canvasHelpers.test.ts`: Unit tests for dimension clamping, object-fit math, background/clipping primitives, WebKit WASM WebP and JPEG fallback encoding, offline image loader cleanup, and JSZip packaging.
- `heicDecoder.test.ts`: Unit tests for HEIC/HEIF detection, native-first decode fast path, and WASM fallback lifecycle transitions.
- `exifReader.test.ts`: Unit tests for JPEG (LE/BE), PNG `eXIf`, WebP `EXIF`, and ISOBMFF/HEIC EXIF & GPS parsing plus malformed/cyclic buffer safety.
- `stitchOverlap.test.ts`: Unit tests for row gradient fingerprinting, multi-frame scrolling overlap trimming, fixed top/bottom bar deduplication, manual `seamOverlapOverrides` clamping, solid/unrelated false-positive guards, mismatched-width normalization, noise/rotation handling, and missing `getImageData` fallback.
- `mergeSplit.test.ts`: Unit tests for `mergeEngine`, `pdfHelper` (single- and multi-page A4/fit PDF 1.4 xref integrity), and `splitEngine` layout geometry, vertical overlap trims, cross-axis alignment, rotation, borders, canvas draw calls, and ZIP slice archives.
- `compressTransformIdCard.test.ts`: Unit tests for `compressEngine` (including `targetBytes` binary search and auto-downscale floor), `transformEngine`, and `idCardEngine` including A4 ID-1 scaling, watermark placements, and batch ZIP exports.
