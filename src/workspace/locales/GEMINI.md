# workspace/locales/
> L2 | Parent: ../GEMINI.md

Four-language UI string dictionaries for `QuickWorkspace` and its 8 tool panels (`en`, `zh`, `ja`, `ko`), including vector `annotate` and `idPhoto` labels.

## Member list
- `en.ts`: English `WorkspaceStrings` dictionary.
- `zh.ts`: Simplified Chinese `WorkspaceStrings` dictionary.
- `ja.ts`: Japanese `WorkspaceStrings` dictionary.
- `ko.ts`: Korean `WorkspaceStrings` dictionary.
- `idPhotoLocale.ts`: 4-language (`en | zh | ja | ko`) UI copy (`IdPhotoLocaleStrings`, `ID_PHOTO_LOCALE_{EN,ZH,JA,KO}`, `getIdPhotoLocaleStrings`) for ID/passport photo standards, compliance tips, matting progress stages, anti-halo edge controls, 4-color compare, and 6-inch/A4 print sheets (zero em-dashes).
- `p1ToolsLocale.ts`: 4-language (`en | zh | ja | ko`) UI copy and formatting helpers (`P1ToolsLocaleStrings`, `getP1ToolsStrings`) for merge seam fine-tuning, multi-page PDF, target-KB compression, Before/After split slider, and EXIF inspection (zero em-dashes).
