# workspace/locales/
> L2 | Parent: ../GEMINI.md

Four-language UI string dictionaries for `QuickWorkspace` and its 6 tool panels (`en`, `zh`, `ja`, `ko`).

## Member list
- `en.ts`: English `WorkspaceStrings` dictionary.
- `zh.ts`: Simplified Chinese `WorkspaceStrings` dictionary.
- `ja.ts`: Japanese `WorkspaceStrings` dictionary.
- `ko.ts`: Korean `WorkspaceStrings` dictionary.
- `p1ToolsLocale.ts`: 4-language (`en | zh | ja | ko`) UI copy and formatting helpers (`P1ToolsLocaleStrings`, `getP1ToolsStrings`) for merge seam fine-tuning, multi-page PDF, target-KB compression, Before/After split slider, and EXIF inspection (zero em-dashes).
