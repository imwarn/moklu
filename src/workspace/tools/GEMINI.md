# workspace/tools/
> L2 | Parent: ../GEMINI.md

Six focused, accessible Quick Tool panels rendered inside `QuickWorkspace`, delegating image synthesis to injected `WorkspaceEngines` with 150ms parameter debouncing, `aria-busy` preview indicators, local IndexedDB draft auto-save (excluding built-in demos), and Studio handoff.

## Member list
- `MockupQuickTool.tsx`: Shots.so-style screenshot beautifier reusing `QuickDesignPreview` (`variant="workspace"` with live `scaleFactor`), 2-level 13-device selector + persisted Browser Light/Dark toggle, 3-second Blur/Pixelate/Spotlight micro-toolbar + `RedactOverlay`, expandable `ExifPrivacyBanner`, `CopyImageButton` (`Cmd/Ctrl+Shift+C`), offscreen PNG export, trust subtext + ghost Pro CTA, local draft auto-save, and non-destructive Studio handoff (raw screenshot + `redactions`).
- `SortableMergeThumb.tsx`: Draggable `@dnd-kit` thumbnail card with move, 90° rotate, and remove controls extracted from `MergeQuickTool`.
- `OverlapTunerModal.tsx`: Interactive 50% ghost-overlay vertical seam fine-tuner dialog (`OverlapTunerModal`, `SeamOverlapPills`) with pointer drag, keyboard stepping, and reset controls paired with `MergeQuickTool`.
- `MergeQuickTool.tsx`: Multi-image drag-and-drop and button-reorderable strip with reverse order, 90° per-item rotation, side-by-side/vertical (auto-activating smart overlap removal + `SeamOverlapPills` + `OverlapTunerModal` per-seam overrides)/2–6-col grid layouts, `cover`/`contain` fit, cross-axis alignment, per-image border, dual-mode Multi-Page A4/fit vs Single-Page Long PDF radio cards, quality slider, clipboard PNG copy, defensive draft restoration, and multi-layer Studio handoff (`mode: 'layers'`).
- `SplitQuickTool.tsx`: Carousel panorama (2–10 slides) and grid matrix (3×3, 2×2, custom rows×cols) splitter with cut-line overlay preview, debounced slicing, dark-safe slice download chips, `CopyImageButton`, local draft auto-save, error-handled ZIP export, and Studio carousel handoff.
- `BeforeAfterSlider.tsx`: Interactive draggable/keyboard vertical split comparison widget (`BeforeAfterSlider`) with `@container` non-overlapping mobile byte badges, 44px coarse-pointer handle target, touch-aware hint copy, 100%/150%/200% zoom pills, wheel zoom, and Copy/Download actions for `CompressQuickTool`.
- `CompressQuickTool.tsx`: Batch offline PNG/JPEG/WebP compressor and format converter with `@container` responsive item cards, lazy WASM WebP encoding (displaying JPEG fallback notice only if an encoded result actually degrades to JPEG), Quality vs Target-KB mode (100KB/200KB/500KB/1MB + custom, auto PNG->WebP switch), auto-downscale fallback banner with preserve-original-dimensions retry, inline & `ModalShell` `BeforeAfterSlider` comparison, expandable EXIF privacy inspector, local draft auto-save, and error-handled ZIP download.
- `ResizeQuickTool.tsx`: Multi-image Resize (draft-buffered px or scale %), Crop, and non-crop Border & Pad workflows with `ResizePreviewStage` busy-aware filmstrip switcher, expandable `ExifPrivacyBanner`, `CopyImageButton`, ≥28–32px touch controls, debounced transforms, local draft auto-save, error-handled batch ZIP export, and full-batch Studio handoff.
- `IdCardQuickTool.tsx`: Front+back ID card slots, 100% offline privacy banner + expandable `ExifPrivacyBanner`, A4 300/150 DPI debounced preview, locale-tracking anti-fraud watermark, grayscale photocopy mode, `CopyImageButton`, local draft auto-save (excluding sample mock IDs), and print-ready PNG export.
- `p1Tools.test.tsx`: Vitest unit and SSR component suite covering 4-language `p1ToolsLocale.ts` (zero em-dashes), `MergeQuickTool` overlap presets & dual-mode PDF cards, `OverlapTunerModal` ghost-overlay math, `CompressQuickTool` target-KB & PNG auto-switch, EXIF inspection, and `BeforeAfterSlider` split/zoom behavior.
