# workspace/
> L2 | Parent: ../GEMINI.md

Above-the-fold instant Quick Workspace UI for all 7 Moklu image tools, built with Dependency Inversion (`WorkspaceEngines`), IndexedDB local draft auto-save (`moklu-workspace-drafts`), multi-layer Studio handoff, and native 4-language (`en | zh | ja | ko`) light/dark presentation.

## Member list
- `types.ts`: Dependency-inverted contracts (`WorkspaceToolId`, `WorkspacePreset`, `WorkspaceLocale`, `WorkspaceExifSummary`, `WorkspaceRedactionRegion`, `WorkspaceMergeFormat`, `WorkspaceMergePdfMode`, `WorkspaceMergePdfPageSize`, `WorkspaceMergePdfOrientation`, `WorkspaceMergeSeamInfo`, `WorkspaceMergeLayout`, `WorkspaceMergeOutput`, `WorkspaceCompressOptions`, `WorkspaceCompressItem`, `WorkspaceEngines`, `StudioHandoffLayer`, `StudioHandoffPayload`, `QuickWorkspaceProps`).
- `batchHelpers.ts`: Pure multi-image batch navigation, safe index clamping, single-item removal, and multi-image Studio handoff payload builder.
- `mergeHandoff.ts`: Multi-layer Studio handoff builder (`buildMergeStudioHandoff`, `isPartialSourceCrop`, `placementToStudioLayer`, `cropSourceRectToDataUrl`) slicing cropped `sourceRect` fragments offscreen and mapping rotated `destRect` placements to Konva center coordinates.
- `draftStorage.ts`: Zero-dependency IndexedDB draft store (`moklu-workspace-drafts`) with `tx.onabort`/`tx.onerror` safety, SSR/missing-IDB silent degradation, and strict built-in demo image exclusion (`serializeDraftImages`, `deserializeDraftImages`, `loadToolDraft`, `saveToolDraft`, `deleteToolDraft`, `clearAllToolDrafts`).
- `draftStorage.test.ts`: Vitest suite verifying IndexedDB draft round-trip, demo image exclusion, `tx.onabort`/`tx.onerror` non-hanging fallback, and SSR silent degradation.
- `useToolDraft.ts`: React hook (`useToolDraft`, `WORKSPACE_DRAFT_DEBOUNCE_MS`) driving debounced auto-save and mount-time hydration across Quick Workspace panels without persisting demo images.
- `ExifPrivacyBanner.tsx`: Expandable amber EXIF & GPS privacy notice (`ExifPrivacyBanner`, `ExifPrivacyBannerProps`) displaying camera, date, and coordinate metadata before local stripping across Mockup, ID Card, Resize, and Annotate panels.
- `redact.ts`: Pure normalized coordinate math and 2D Canvas Blur/Pixelate/Spotlight renderer (`clampNormalizedRegion`, `normalizeDragBox`, `resizeRegionByCorner`, `moveRegionByDelta`, `computeMockupStageMetrics`, `stagePointToImageNorm`, `imageNormRectToStageNorm`, `applyRedactionsToCanvas`, `renderRedactedImageDataUrl`) aligned with `studioHandoff.ts`.
- `redact.test.ts`: Vitest suite verifying normalized coordinate clamping, drag/resize/move math, mockup stage projection, and blur/pixelate/spotlight canvas rendering.
- `RedactOverlay.tsx`: Interactive 3-second redaction and spotlight overlay (`RedactToolbar`, `RedactOverlay`, `RedactToolMode`) layered above `QuickDesignPreview` in `MockupQuickTool` with drag creation, 4-corner resizing, and Delete/Backspace removal.
- `AnnotateOverlay.tsx`: Reusable floating pill toolbar (`AnnotateToolbar` with `role="toolbar"`, `focusgroup="toolbar wrap"` + roving-tabindex fallback, 5 vector tools, 8-swatch color popover, adaptive stroke/font slider, Undo/Redo), interactive SVG overlay stage (`AnnotateCanvas` with Pointer Events, 8-handle dashed blue `#3b82f6` selection box, inline text editor), and keyboard shortcut hook (`useAnnotateShortcuts`).
- `AnnotateModal.tsx`: Accessible inline annotation dialog (`AnnotateModal`, `ModalShell`) letting Mockup, Resize, and Merge panels open floating-toolbar markup over any image and bake full-resolution PNG output on Save.
- `i18n.ts`: Code-split 4-language `WorkspaceStrings` registry (`hasWorkspaceLocale`, `preloadWorkspaceLocale`, `preloadAllWorkspaceLocales`, `getWorkspaceStrings`) dynamically importing `locales/{en,zh,ja,ko}` per route with automatic eager preload in SSR/Node/Vitest.
- `locales/`: Complete EN/ZH/JA/KO UI dictionaries (`en.ts`, `zh.ts`, `ja.ts`, `ko.ts`, `p1ToolsLocale.ts`) covering tabs, errors, `.heic`/`.avif` decode progress, EXIF privacy notices, redaction tools, annotation controls, seam tuning, multipage PDF, target-KB compression, split-slider comparison, and localized default ID-card watermarks (zero em-dashes).
- `themeTokens.ts`: WCAG AA light and dark Neutral Zinc + Signal Orange semantic token maps (`getWorkspaceThemeTokens`) bound to `src/index.css` variables.
- `uiPrimitives.tsx`: Shared accessible primitives (`DropZone` with `.heic`/`.avif` support, inline decode progress, and `format_rejected` telemetry, `CopyImageButton` with `Cmd/Ctrl+Shift+C` shortcut and 1.5s checkmark feedback, `PrivacyBadge`, `PreviewBusyOverlay`, `SegmentedControl`, `SliderField`, `StudioHandoffButton`, `ColorSwatchRow`, `DraftStatusBar`).
- `useDebouncedValue.ts`: Shared 150ms debounce hook (`useDebouncedValue`, `WORKSPACE_DEBOUNCE_MS`) preventing full-res canvas churn during slider drags and typing.
- `demoAssets.ts`: Deterministic SVG demo screenshot and sample ID card generators (`createDemoScreenshotDataUrl`, `createDemoImageInput` tagged with `isDemo: true`).
- `canvasUtils.ts`: Memory-safe file decoding with pre-reencode EXIF parsing, original byte-size preservation, and lazy local HEIC decode (`readFileAsImageInput`), lazy WASM WebP fallback before opaque JPEG fallback (`finalizeCanvasOutput`), blob downloads, clipboard PNG copy (`copyImageToClipboard`, `isClipboardImageSupported`), byte formatting, and full-res offscreen HTML5 Canvas mockup PNG exporter with optional baked redactions.
- `defaultEngines.ts`: Browser-native fallback `WorkspaceEngines` (`merge` returning `WorkspaceMergeLayout` + seam metadata + multi-page/single-page PDF, `split`, `compress` with target-KB binary search & auto-downscale, `transform`, `idCard`, on-demand dynamic-import `packZip`) for standalone execution when `src/tools` is not injected.
- `engineAdapter.ts`: Concrete lazy DIP adapter (`createToolsWorkspaceEngines`, `parseBackgroundFill`, `formatSuffixedFilename`) dynamically importing `src/tools/{mergeEngine,splitEngine,compressEngine,transformEngine,idCardEngine,canvasHelpers}` on demand while preserving per-seam overlap overrides, multi-page PDF options, target-KB & original-dimension compression options, EXIF propagation, free-aspect crop preservation, safe filename stems, and guaranteed `LoadedImageItem` disposal.
- `engineAdapter.test.ts`: Vitest suite verifying merge layout/seam/PDF forwarding, target-KB/EXIF compress mapping, free-aspect crop preservation, filename suffix/fallback safety, gradient parsing, and disposal guarantees.
- `QuickWorkspace.tsx`: Root workspace shell exporting `QuickWorkspace`, `hasWorkspaceTool`, `preloadWorkspaceTool`, and `preloadAllWorkspaceTools` with on-demand code-splitting for all 7 tool panels and fallback `defaultEngines`, tab hover/focus chunk prefetching, automatic eager preload in SSR/Node/Vitest, keyboard-navigable 7-tool tablist (Arrow/Home/End + focus migration), global `Cmd/Ctrl+V` Signal Orange paste pulse with multi-image switch-to-Merge banner persisting via `saveToolDraft('merge', ...)`, locale-preserving panel keys, route preset syncing, theme resolution, and engine merging.
- `index.ts`: Barrel exporting `QuickWorkspace`, `AnnotateModal`, `AnnotateToolbar`, `AnnotateCanvas`, `useAnnotateShortcuts`, contracts, i18n helper, multi-layer merge handoff, IndexedDB draft storage/hook, demo utilities, and fallback engines.
- `workspace.test.tsx`: Vitest suite verifying SSR rendering across all 7 tools, 4 locales (zero em-dashes), light/dark semantic tokens, Annotate toolbar/modal/standalone flows & inline annotate triggers, global paste/HEIC/EXIF/redaction/13-device flows, `CopyImageButton`, `QuickDesignPreview` scaleFactor, vertical overlap-removal toggle, `buildMergeStudioHandoff` multi-layer geometry & cropping, `DraftStatusBar`, preset propagation, demo generators, and dynamic ZIP packing.
- `tools/`: Seven focused tool panels (`MockupQuickTool`, `MergeQuickTool` + `SortableMergeThumb` + `OverlapTunerModal`, `SplitQuickTool`, `CompressQuickTool` + `BeforeAfterSlider`, `ResizeQuickTool`, `AnnotateQuickTool`, `IdCardQuickTool`, and `p1Tools.test.tsx`).
