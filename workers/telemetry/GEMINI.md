# workers/telemetry/
> L2 | Parent: ../GEMINI.md

Cloudflare Edge Worker (`moklu-telemetry`) routed across `moklu.app/*` that:
1. Enforces `public/_headers` `Content-Security-Policy` (including `'wasm-unsafe-eval'`), `Cross-Origin-Opener-Policy`, security headers, bfcache-safe `Cache-Control` (`public, no-cache` on 140 localized SSG HTML routes, `no-store` on `/healthz*`/`/_telemetry*`/unknown routes/errors, `immutable` on `/assets/*` and `/models/*`), `CDN-Cache-Control` + `cf.cacheEverything` edge caching (`moklu-edge-v3`), content-negotiated static-asset soft-200/4xx handling (browser HTML navigations receive localized `/404.html` or `/{zh,ja,ko}/404.html` with `404 text/html`, `no-store`, `Vary`, `noindex, nofollow`; subresources and `curl` receive `404 text/plain`, `no-store`, `noindex, nofollow`, never cached), canonical `301` `/en` & `/en/<known-slug>` redirects, and localized `404.html` + real HTTP `404` + `X-Robots-Tag: noindex, follow` on unknown non-asset routes at the Cloudflare edge in front of Coolify.
2. Collects same-origin privacy-sanitized funnel beacons (`POST /_telemetry`, including `not_found_view`) into Cloudflare D1 (`moklu-funnel`, daily rollup table `funnel_daily` with zero cookies, zero IPs, and zero PII).
