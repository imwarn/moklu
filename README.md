# Moklu

**Beautiful mockups, made simple.**

Moklu is an open-source screenshot and mockup studio built on [PixelDeck](https://github.com/Pr0xS/PixelDeck). It will combine fast, editable templates with a flexible canvas editor for browser and device mockups.

> Work in progress: the initial development branch will preserve the PixelDeck source and MIT attribution as the foundation for Moklu v0.1.0.

## Planned v0.1 scope

- Retain PixelDeck's Konva canvas, layers, editing and export workflows.
- Add browser-window mockups beside device mockups.
- Add a generic single-canvas workflow with custom aspect ratios.
- Add editable quick templates and screenshot replacement.
- Keep the first release client-side and privacy-friendly.
