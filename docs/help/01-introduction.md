Moklu is a visual editor for designing App Store and Play Store screenshot sets. You build one or more slide groups, arrange layers on them (device mockups, text, images, shapes, backgrounds), adjust per-platform formats and per-language content, then export PNGs — either from the browser or via the CLI for batch/automated pipelines.

## A quick way to start

1. Click **Quick Design** in the toolbar and upload a screenshot (you can also add one later).
2. Select a browser or device frame, an artboard preset and a background style.
3. Choose **Apply Design** to create editable layers, then use the right properties panel to fine-tune the selected frame.
4. Click **Canvas Size** at any time to change the artboard ratio or enter custom pixel dimensions. **Keep size & center** preserves all layer sizes; **Scale content to fit** scales artwork uniformly without removing layers.
5. Use **↓ PNG** to download the active canvas. Projects are saved locally in your browser.

**Quick Design reapplies a style** and replaces the current slide's layers. **Canvas Size only changes the artboard** and retains the existing layers. For multi-slide App Store/Play Store sets, use the advanced Slides, Formats, and Templates tools.
