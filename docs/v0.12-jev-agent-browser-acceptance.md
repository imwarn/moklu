## 4. 建议执行命令

可在本地已安装 Node 22 且已经 `npm ci` 的仓库中执行：

```sh
# 线上只读连通性、响应头、JS/CSS 资源校验（输出 JSON）
MOKLU_DEPLOY_URL=https://moklu.app node scripts/check-deployment.mjs

# 在线浏览器冒烟 + 独立浏览器 profile 数据可靠性
MOKLU_DEPLOY_URL=https://moklu.app npx playwright test --config tests/live/playwright.config.mjs

# 单独只跑数据可靠性：
MOKLU_DEPLOY_URL=https://moklu.app npx playwright test tests/live/reliability.spec.mjs --config=tests/live/playwright.config.mjs --project=chromium-desktop
```

`reliability.spec.mjs` 会在临时浏览器 profile 中创建测试项目、导出 PNG/JSON 并验证恢复；它不清除或操作你现有浏览器 profile 的用户数据。不要在含真实用户信息的 profile 里复制这些步骤。
